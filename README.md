istema de Cadastro e Doação de Animais 🐾
Este projeto foi desenvolvido como trabalho acadêmico para a disciplina de Desenvolvimento Web 1. O objetivo é criar um site voltado ao cadastro de animais e à divulgação de animais disponíveis para adoção, incentivando a adoção responsável e o cuidado com os animais.

O sistema foi desenvolvido utilizando HTML5 e CSS3, aplicando conceitos de estruturação de páginas web, estilização, organização de conteúdo e criação de interfaces.

O projeto busca oferecer uma interface simples, intuitiva e visualmente agradável, facilitando o acesso às informações dos animais e promovendo a conscientização sobre a adoção.
Tecnologias utilizadas
- HTML5
- CSS3
Objetivo
Aplicar os conhecimentos adquiridos na disciplina de Desenvolvimento Web 1 por meio da criação de um sistema web de cadastro e doação de animais, unindo aprendizado técnico e uma proposta de impacto social.
